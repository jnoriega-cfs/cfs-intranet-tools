CFS TECH MINUTE
Issue #13 | September 1, 2026
IT'S NOT ABOUT WHICH TOOL — IT'S WHAT YOU TYPE
Charlie, Copilot, and every other AI tool work the same basic way: whatever you type becomes part of that conversation, processed and, in some cases, retained. That's true no matter how trustworthy the tool is.

Our AI Acceptable Use Policy (IT-AI-001) puts it simply: if it's identifying information about someone we support, or sensitive information about a staff member, it doesn't belong in an AI prompt — full stop.
WHAT THIS LOOKS LIKE IN PRACTICE
Same question, asked two different ways:
  1. Instead of: "Summarize this incident report for John Smith, DOB 3/4/1990, regarding his medication refusal on 8/12…" — ask: "How should I document a medication refusal in general terms?"
  2. Instead of: pasting a staff member's full personnel file to draft a performance note — ask: Charlie for CFS's performance documentation template, then fill in the specifics yourself, offline.
  3. Instead of: asking an AI tool to "remember" a password or account number for you — use a password manager, or ask the Help Desk.
The pattern: ask AI tools for the general process, the template, the policy — then apply it yourself with the specific, sensitive details kept out of the tool entirely.
Pro tip: If you wouldn't post it on a public forum, don't paste it into an AI chat window either. Same test, same answer.
